# Spaceship
Programming Language Design final project Spaceship DSL

a. Clone to your local machine
"<> Code" -> "HTTP" -> "copy to clipboard"
  > git clone 'url'
git clone https://github.com/<your-username>/Spaceship.git
cd Spaceship

b. Create new branch
git checkout -b 'my-feature-branch'

c. display all branch
#local branch
 > git branch
#local and public branch
> git branch --all

d. change branch
#switch branch
> git switch 'branchName'

#branch status
> git status

e. add file for commit
> git add 'file'
#add all file in one go
> git add .

f. commit file
> git commit -m 'message'

g. push commit of your branch so everyone can see
> git push

h. see all changes / update the repository 
> git fetch
or
> git fetch --all

i. retrieve all changes
> git pull
